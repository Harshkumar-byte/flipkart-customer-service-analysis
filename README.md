# 📞 Flipkart Customer Service Analysis

## 📌 Project Overview

This project analyzes Flipkart’s customer service operations to identify factors affecting customer satisfaction and customer retention. Using customer interaction and call center data, the analysis uncovers insights related to response time, customer sentiment, call handling efficiency, and overall support performance.

The goal of this project is to transform raw customer service data into actionable business insights that can help improve customer experience and operational efficiency.

---

## 🎯 Business Problem

Despite having a large customer base and strong platform traffic, Flipkart faces challenges in maintaining high customer retention.

This analysis aims to answer key business questions such as:

* Does faster response time improve customer satisfaction?
* How does customer sentiment impact CSAT scores?
* Which call centers perform better operationally?
* Does longer call duration indicate inefficient issue resolution?
* Which operational factors are most related to customer satisfaction?

## 📌 Key Insights

* Faster response times generally resulted in higher CSAT scores.
* Negative customer sentiment strongly correlated with lower satisfaction ratings.
* Certain call centers consistently outperformed others in handling customer issues.
* Longer call durations often indicated inefficient resolution processes.
* Customer experience varied significantly across support locations.

---

## ✅ Recommendations

* Reduce response time through better ticket prioritization.
* Improve support training for handling negative customer interactions.
* Standardize support workflows across all call centers.
* Monitor low-performing centers using KPI dashboards.
* Optimize call handling processes to reduce unnecessary call duration.
